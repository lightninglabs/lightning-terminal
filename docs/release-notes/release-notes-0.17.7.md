* [Add a release build workflow on tag
  push](https://github.com/lightninglabs/lightning-terminal/pull/1418):
  Pushing a release tag now builds all release artifacts in CI and
  attaches them to a draft GitHub release automatically, the same way
  lnd and taproot-assets are released, so releases no longer require a
  manual build.
